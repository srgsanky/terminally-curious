Naming a visual style gives you a more concrete starting point when asking an AI to build a website. “Make it clean and modern” leaves plenty of room for interpretation; “warm editorial, with cream backgrounds, terracotta accents and serif headlines” gives the design a direction.

Here are 15 styles to use as a reference. The labels mix **color palettes**, **visual treatments** and **layout patterns**, so they can overlap: a bento grid can use a sage-and-cream palette, for example.

The samples are original mockups for a fictional product called **Gather**. Shared branding and copy make the changes in color, type, spacing and layout easier to compare. Select any sample to view it at full size.

To use the guide in a prompt, combine the choices that matter:

> Build a productivity landing page with a sage-and-cream palette and a bento grid. Use warm ivory backgrounds, muted green accents, thin borders and plain sans-serif headings. Give the main message the most space and keep the supporting cards compact.
